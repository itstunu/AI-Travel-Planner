## ✨ Features

### 🧠 4 Powerful Search Algorithms

| Algorithm | Strategy | Best For |
|-----------|----------|----------|
| 🛑 **BFS** | Breadth-First Search | Least number of stops |
| 💰 **UCS** | Uniform Cost Search | Cheapest route |
| ⚡ **Greedy BFS** | Greedy Best-First | Fastest route |
| ⭐ **A\*** | A* with heuristic | Best overall route |

### 🎯 Smart Filters

- **💰 Budget Constraints** - Set maximum travel cost in Taka
- **⏱️ Time Limits** - Set maximum travel time in minutes

### 🗺️ Comprehensive Coverage

- **20+ Cities** across Bangladesh
- **40+ Routes** with real travel data
- **Ratings** for each route (1-5 stars)
